== Synopsis
[verse]
airspace [-h|--help] [-v|--version] <subcommand> [<subcommand-options>...] [<subcommand-arguments>...]

== Description

AirSpace is an i3-like tiling window manager for macOS

*airspace* command line program is used to manipulate AirSpace and query its state.

See https://nikitabobko.github.io/AeroSpace/commands for available <subcommand> options (upstream AeroSpace documentation)

See each <subcommand> individual man page for <subcommand-options> and <subcommand-arguments>

== Options

-h, --help:: Print help
